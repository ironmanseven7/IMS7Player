IMS7 Player

How to install it on a Fire TV Stick

Before you start

  • A Fire TV Stick, plugged in and connected to wi-fi.
  • Your IPTV details: the server address, username and password - or the M3U link your provider sent you.
  • About ten minutes.
Already have IMS7 Player on this Fire TV? Uninstall it first - step 3. This is needed once, and once only: the app is now signed properly, and Android will not install it over an older copy. From then on it updates itself.
Version 1.11.4 · October 2026
1

Get the Downloader app

On the Fire TV home screen, go to the magnifying glass (Find) at the top left and choose Search.

Type Downloader, pick it from the list - the orange icon by AFTVnews - and choose Get or Download.

When it finishes, leave it for now. Do not open it yet.

What the search looks like
2

Let Downloader install apps

Go to Settings (the gear at the top of the home screen), then:

  1. My Fire TV
  2. Developer options
  3. Install unknown apps
  4. Find Downloader in the list and press OK so it says ON

No Developer options? Go to My Fire TV → About, move down to Fire TV Stick and press OK seven times. It then appears.

The switch must read ON
3

Remove the old copy (only if you have one)

Skip this if IMS7 Player has never been on this Fire TV.

  1. Settings → Applications
  2. Manage Installed Applications
  3. IMS7 Player
  4. Uninstall

You will have to type your IPTV username and password again afterwards. This is a one-off: future updates install themselves without any of this.

Choose Uninstall
4

Type the address into Downloader

Open Downloader. If it asks for permission to access files, choose Allow.

On the Home tab there is a box for a web address. Select it and type:

ironmanseven7.github.io/IMS7Player

No www and no http - just as printed. Then choose Go.

The download is about 4 MB and takes a few seconds.

The address box on the Home tab
5

Install it

When the download finishes, a grey box appears asking whether to install IMS7 Player. Choose Install (bottom right).

Wait for App installed, then choose Open.

Downloader then offers to delete the file it downloaded. Choosing Delete is fine - the app itself is already installed.

"App not installed" instead? An older copy is still on the stick. Go back to step 3, uninstall it, then try again.
Choose Install, then Open
6

Sign in

The app opens on a sign-in screen. The quickest way:

Paste your M3U link into the Server URL box - the long link your provider sent, the one with username= and password= in it. The app splits it up and fills in all three boxes for you.

Otherwise type them yourself:

  • Server URL - e.g. http://your-panel.com:8080
  • Username and Password - exactly as given, capitals matter

Leave Remember on this machine ticked, then choose Connect.

Paste the M3U link into the first box

Using it with the remote

ButtonWhat it does
ArrowsMove between the columns: categories, channels, and the player on the right. Up from the top of a column reaches the menu bar.
OKChooses whatever is highlighted.
BackLeaves full screen. Pressed again, it leaves the app.
MicrophoneNot the Alexa button - use the Voice button in the app's menu bar, then say "watch ESPN", "bring up movies", "multiview".

Worth knowing

Full screenThe Full screen button next to the title, or OK on the picture.
WidescreenFills a 21:9 screen instead of leaving black bars at the sides. On a normal TV it is not needed.
MultiviewUp to four channels at once. Pick one tile with OK to give it the sound; OK again makes the grid full screen.
Next episodeSeries play the next episode on their own, with a ten second countdown you can stop.
FavouritesThe star button beside a channel's name; they gather under the Favourites tab.
BufferingIf a channel stutters, set Buffering in the menu bar to Smooth.
Updates happen on their own now The app checks for a newer version and can install it without any of the steps in this guide. You will see an Update banner, or you can switch on automatic updates when it offers. Only rarely - when the app itself changes rather than its screens - does it ask you to confirm an install.

If something goes wrong

What you seeWhat it means
"App not installed" when installing An older copy of IMS7 Player is still on the stick. Uninstall it (step 3) and install again.
"Your internet connection is blocking this login" Your home network, not the app. Some providers (AT&T's ActiveArmor, for one) block sign-ins to IPTV addresses. Allow the address in your router's security settings, ask your IPTV provider for a different address, or try the stick on a phone hotspot to confirm.
"Login rejected by the panel" The username or password is wrong, or the line has expired. Capitals matter.
A film plays with no sound That file's soundtrack is Dolby Digital or DTS, which no browser can decode - the app says so after a few seconds. Try another copy of the same title, or play it in VLC.
A channel never starts Usually the line's connection limit: something else is already watching. The app shows how many connections your line allows.
Picture stutters Set Buffering to Smooth in the menu bar. It waits a little longer before starting but holds up better.
Nothing above helps Open Diagnostics in the menu bar. It lists exactly what the panel replied, with the password hidden, which is usually enough to tell what is wrong.
