Xtream Player
Install Guide

Putting the TV app on a Fire TV Stick.

There are 7 steps. Each one has its own page and a picture.

You need the Fire TV remote and about 10 minutes.

Please note

The pictures are drawings, not photos. The real screen will look similar, not identical.

Your remote

Arrows move the highlight.

The middle button is OK. It chooses things.

Back is below and to the left.

1
Get Downloader

On the Fire TV, go to Find, then Search.

Type Downloader and choose Get.

Already have it? Go to Step 2.

2
Allow installing

Without this, the install is refused.

Go to Settings, then:

  1. My Fire TV
  2. Developer options
  3. Install unknown apps
  4. Turn Downloader ON
3
Type the address

Open Downloader. Press OK on the address box and type:

ironmanseven7.github.io/IMS7Player

No spaces. The dots and the slash matter.

4
Let it download

A bar fills from left to right.

The file is small. It takes a few seconds.

If a page appears

Move to the Download the APK button and press OK.

5
Choose Install

A box asks if you want to install it.

Move right to Install and press OK.

If it says blocked

Do Step 2 again. The permission is off.

6
Open it

The box says App installed.

Choose Open.

Later, find Xtream Player with your other apps.

7
Sign in

Type these three things, then choose Connect.

Server address
Username
Password

Ask Clayton

These are not printed here. Write them on the lines.

Using the app

The highlighted item has a thick blue outline.

Left and right move between the three columns.

Up and down move inside a column.

OK starts it. Back leaves full screen.

Voice

There is a Voice button at the top of the app.

Choose it, then speak. For example:

  • "watch CNN"
  • "bring up movies"
  • "pause"

The first time, the Fire TV asks to use the microphone. Choose Allow, then press Voice again.

If it goes wrong

"App not installed"
Do Step 2 again.

Page not found
Check the address for typing mistakes.

No picture
Choose Diagnostics at the top and read it out.

Picture keeps stopping
Set Buffering to Smooth.
