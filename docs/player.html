XtreamPlayer

A browser player for your own IPTV subscription. Live TV, films, series, guide and favourites.

  1. Install Node.js

    Pick the LTS version. It is what runs the player.

    Get Node.js

  2. Download the player

    Unzip it anywhere — your Desktop is fine.

    Download (about 0.5 MB)

  3. Start it

    Windows: double-click Start Player.bat in the unzipped folder.

    Mac or Linux: open Terminal in that folder and run:

    node server.js

    Your browser opens at http://127.0.0.1:8787.

  4. Sign in with your own subscription

    Enter the server address, username and password from your IPTV provider.

    Easiest way: paste your provider's whole M3U link into the Server URL box — it fills in all three fields for you.

Why does it need to run on your computer?
IPTV panels don't send the headers a browser needs to talk to them directly, so a small local relay does it instead. It runs only on your own machine, on 127.0.0.1, and your credentials are never sent anywhere except to your own provider.
Watching on Android instead?
There is an app version that needs no computer — download the APK.
